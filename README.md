# astrbot_plugin_qiniu_image

七牛 Modelink 原厂 `bypass` 协议绘图 / 改图插件，适用于 AstrBot。

## 使用

直接用自然语言请求绘图或改图，例如：

```text
帮我画一只穿宇航服的柴犬
把这张图改成夜景
```

插件默认通过 `draw_image` 工具触发，也可以在 `triggers` 配置中添加确定性触发词。改图时可直接发送图片或引用图片消息。

## 内置风格

插件会在同一次提示词改写中，根据用户需求选择一个合适的内置风格或借用其部分特征；只有风格与需求明显冲突时才不选择。用户明确指定的内容和风格始终优先，不会为了套模板而替换角色、品牌、文案、构图或配色。改图时只有用户明确要求风格化，才会改变原图画风。

当前内置风格：

- 文艺电商联动物料
- 俄国构成主义
- 错位矩形·强故障版
- 错位矩形·诗意窗口版
- 混合媒介·照片与素描
- 半调双色雕刻
- 半调杂志
- 波普与水墨喷溅
- 克莱因秩序
- 米白红色电路图
- Y2K 与波普艺术
- 赛璐璐平涂与思维爆发

自动选择会优先考虑：两种错位矩形风格、半调杂志、波普与水墨喷溅、米白红色电路图、赛璐璐平涂与思维爆发。

style_mode 控制选用方式：auto 智能选择、explicit_only 仅明确点名时选择、disabled 不注入内置风格库。style_strength 控制风格表现强度。内置风格依赖提示词改写，因此 rewrite_scope=never 时不会生效。

## 配置

配置项及默认值见 `_conf_schema.json`。至少需要填写 `api_key`；默认使用后台出图模式，完成后会主动发送图片。
