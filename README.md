# astrbot_plugin_qiniu_image

七牛 Modelink 原厂 `bypass` 协议绘图 / 改图插件，适用于 AstrBot。

## 使用

直接用自然语言请求绘图或改图，例如：

```text
帮我画一只穿宇航服的柴犬
把这张图改成夜景
```

插件默认通过 `draw_image` 工具触发，确保请求先由主聊天模型理解完整上下文和 Bot 人设；也可通过 `triggers` 配置确定性的直接出图触发词。改图时可直接发送图片或引用图片消息。

## 内置风格

插件会在同一次提示词改写中，根据用户需求选择一个合适的内置风格或借用其部分特征；只有风格与需求明显冲突时才不选择。用户明确指定的内容和风格始终优先，不会为了套模板而替换角色、品牌、文案、构图或配色。改图时只有用户明确要求风格化，才会改变原图画风。

当前内置风格：

- 净色动画壁纸
- 文艺电商联动物料
- 俄国构成主义
- 错位矩形·强故障版
- 错位矩形·诗意窗口版
- 混合媒介·照片与素描
- 半调双色雕刻
- 半调杂志
- 波普与水墨喷溅
- 克莱因秩序
- 米白红色电路图
- Y2K 与波普艺术
- 赛璐璐平涂与思维爆发

自动选择会优先考虑：净色动画壁纸、两种错位矩形风格、半调杂志、波普与水墨喷溅、米白红色电路图、赛璐璐平涂与思维爆发。

插件还注册了 `list_image_styles` 查询工具。普通聊天中用户询问“你会哪些画风”或要求推荐风格时，聊天模型可以直接读取与实际预设同源的风格目录，无需维护一份容易过期的独立 Skill。

默认工具链路中，主聊天模型先结合自身人设、完整群聊上下文、用户意图和必要考据完成创作决策，只把这一份完整方案交给提示词优化模型，不再同时注入用户原始短句。优化模型不能自行新增或替换主体、剧情、服装、动作、场景、构图、配色和画风；只有内置的全局质量规则与风格路由可以在方案之外注入。关键词直出会绕过主聊天模型，并把触发词后的文本视作完整方案，适合确定性的完整提示词。

调用 `draw_image` 时，聊天模型应直接识别常见作品、角色和昵称，并补全关键官方信息；知识不足以可靠还原或无法唯一识别主体时使用 Web 搜索，并且必须先等待搜索结果，再调用绘图工具。搜索和绘图不能并行。这个限制通过工具说明引导聊天模型执行，插件本身无法拦截 AstrBot 对其他工具的调度。

插件按会话在内存中保存最近一次实际提交给图片模型的提示词，包括安全审核重写后的版本，并注册 `get_last_image_prompt` 工具。后续用户要求“把刚才那张改成夜景”“保持角色换个动作”时，主聊天模型可以先读取真实执行稿再编写修改方案，避免只凭表面回复猜测中间优化结果。记录不落盘，插件重启后清空，也不会默认把长提示词发到群聊。

优化时 `anime style`、`masterpiece`、`highly detailed` 等泛化质量词不会被误判为完整画风。内置全局审美规则会在所有普通优化中注入，进一步约束动画画面使用大色块、低视觉频率、受控边缘密度、清晰边缘层级、少量内部轮廓线和大块阴影，并抑制碎阴影、微纹理、微对比和无必要高光。

内置风格名称只用于路由和日志，不会发送给图片模型。插件会删除内部风格标记、中文风格名及别名，只保留展开后的构图、色彩、线条和材质描述。日系动漫、漫画及游戏角色默认使用官方日文作品名、角色名和画内字样，不使用中文译名作为海报装饰文字。

风格优先级依次为：主聊天模型提交的完整方案及其中明确点名的内置或外部风格；改图时原图画风保持；方案未指定风格时，根据 `style_mode` 决定是否从相容的内置风格中自动选择并优先高偏好项。`style_strength` 控制内置风格的表现强度。全局审美规则始终约束最终执行质量，但不替换方案指定的主体、构图或配色。

提示词优化与全局审美规则为固定流程。优化模型不会查看原图，也不会读取额外历史；会话和原图理解统一由拥有完整上下文和人设的主聊天模型负责。原图只会直接交给图片模型执行改图。

## 安全转译

首次出图前不进行风险词检测，也不注入安全转译规则。只有图片平台实际返回安全审核拒绝后，插件才会生成安全替代提示词并继续尝试，固定最多 5 级。安全程度逐级递进：先通过同义替换、隐晦措辞等措辞级调整尝试保留原画面（不改动服装、场景、姿势与构图），前两级还会优先使用动画角色插画、角色立绘、轻小说封面、动画剧照等二次元插画语境措辞，并避免私密场景、暴露服装与挑逗姿势叠加；仍被拒绝后才依次增加遮盖并减弱暗示、改为完整家居服或时装、端庄日常服装与中性场景，最后才是全年龄普通角色插画。某一级的安全改写模型若拒绝回答、返回空内容或无效结果，插件不会立即终止，而会继续尝试更保守的下一级；图片平台再次拒绝时同样推进一级。全部级别都无法产出可用图片后才失败。它不会原样生成裸露、性行为或未成年人性化内容。`moderation` 默认 `low`（放宽审核阈值，仅对中等敏感内容有效），如遇上游不支持该参数或需要更严审核，可设为 `auto` 恢复上游默认。

`rewrite_provider_ids` 使用 AstrBot 的有序模型选择器：第一项是主优化模型，后续项按顺序作为回退模型；留空则跟随当前会话。每个模型固定最多调用 3 次。全部优化模型均失败时，本次绘图会终止，不会把未经优化的方案直接发给图片模型。该选择器在 AstrBot v4.28.0 可用，目前属于 AstrBot 内部配置控件，未来大版本若调整内部接口可能需要随之适配。

图片请求遇到网络异常、限流、5xx 或异常响应时固定最多尝试 4 次，单次请求总超时为 480 秒；鉴权、权限和参数错误不会进行无意义重试。优化模型只需要良好的中文理解、指令遵循和提示词整理能力，不需要视觉能力。

## 配置

配置页面保留 API Key、图像模型、提示词优化模型、画质、尺寸、审核严格度、并发数、风格模式、风格强度和可选直接触发词。默认模型为 `openai/gpt-image-2.5-sunburst`，默认并发数为 3。插件固定使用官方 API 和 PNG 输出；主模型工具调用采用后台出图，关键词直出同步返回结果，并使用具有冗余的超时、重试和安全回退。改图输入支持 PNG、JPEG、WebP、GIF，单张本地输入按 Modelink 文档限制为 40 MB；输出接收上限为 80 MiB，为 4K PNG 留出余量。
