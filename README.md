# astrbot_plugin_qiniu_image

七牛 Modelink 原厂 `bypass` 协议绘图 / 改图插件，适用于 AstrBot。

## 使用

直接用自然语言请求绘图或改图，例如：

```text
帮我画一只穿宇航服的柴犬
把这张图改成夜景
```

插件默认通过 `draw_image` 工具触发，也可以在 `triggers` 配置中添加确定性触发词。改图时可直接发送图片或引用图片消息。

## 内置风格

插件会在同一次提示词改写中，根据用户需求选择一个合适的内置风格或借用其部分特征；只有风格与需求明显冲突时才不选择。用户明确指定的内容和风格始终优先，不会为了套模板而替换角色、品牌、文案、构图或配色。改图时只有用户明确要求风格化，才会改变原图画风。

当前内置风格：

- 文艺电商联动物料
- 俄国构成主义
- 错位矩形·强故障版
- 错位矩形·诗意窗口版
- 混合媒介·照片与素描
- 半调双色雕刻
- 半调杂志
- 波普与水墨喷溅
- 克莱因秩序
- 米白红色电路图
- Y2K 与波普艺术
- 赛璐璐平涂与思维爆发

自动选择会优先考虑：两种错位矩形风格、半调杂志、波普与水墨喷溅、米白红色电路图、赛璐璐平涂与思维爆发。

插件还注册了 `list_image_styles` 查询工具。普通聊天中用户询问“你会哪些画风”或要求推荐风格时，聊天模型可以直接读取与实际预设同源的风格目录，无需维护一份容易过期的独立 Skill。

函数工具调用和关键词直出最终都会进入同一套提示词改写与出图流程。用户原话是唯一的创作需求来源；函数工具参数只用于解析“刚才那个”“换种风格”等指代、延续用户明确要求保留的内容，以及补充主体身份与官方名称，不会采用聊天模型自行增加的服装、动作、背景、构图或画风。关键词直出会绕过聊天模型，因此不会自动取得聊天模型掌握的会话指代信息。

调用 `draw_image` 时，聊天模型应直接识别常见作品、角色和昵称。只有确实无法唯一识别主体时才使用 Web 搜索，并且必须先等待搜索结果，再调用绘图工具；搜索和绘图不能并行。这个限制通过工具说明引导聊天模型执行，插件本身无法拦截 AstrBot 对其他工具的调度。

改写时 `anime style`、`masterpiece`、`highly detailed` 等泛化质量词不会被误判为完整画风。全局审美规则会在所有普通改写中注入，约束每种风格保持干净、通透、层级清晰；可通过 `global_quality_prompt` 自定义或清空关闭。

内置风格名称只用于路由和日志，不会发送给图片模型。插件会删除内部风格标记、中文风格名及别名，只保留展开后的构图、色彩、线条和材质描述。日系动漫、漫画及游戏角色默认使用官方日文作品名、角色名和画内字样，不使用中文译名作为海报装饰文字。

风格优先级依次为：用户原话中的明确内容与画面硬性要求；用户明确点名的内置或外部风格；用户说“换种风格”等明确委托选择时，由提示词改写模型依据内置风格库重新选择；改图时原图画风保持；其余未指定情况从相容的内置风格中自动选择并优先高偏好项；`style_strength` 决定表现强度。聊天模型生成的工具草稿不参与风格决策。全局审美规则始终约束最终执行质量，但不替换用户指定的主体、构图或配色。

style_mode 控制选用方式：auto 智能选择、explicit_only 仅明确点名时选择、disabled 不注入内置风格库。style_strength 控制风格表现强度。内置风格依赖提示词改写，因此 rewrite_scope=never 时不会生效。

## 安全转译

首次出图前不进行风险词检测，也不注入安全转译规则。只有图片平台实际返回安全审核拒绝后，插件才会按 `safety_rewrite_attempts` 生成安全替代提示词并继续尝试，默认最多 5 次。安全程度分五级递进：先通过同义替换、隐晦措辞等措辞级调整尝试保留原画面（不改动服装、场景、姿势与构图），前两级还会优先使用动画角色插画、角色立绘、轻小说封面、动画剧照等二次元插画语境措辞，并避免私密场景、暴露服装与挑逗姿势叠加；仍被拒绝后才依次增加遮盖并减弱暗示、改为完整家居服或时装、端庄日常服装与中性场景，最后才是全年龄普通角色插画；不会第一次就直接套用最保守版本。它不会原样生成裸露、性行为或未成年人性化内容。`moderation` 默认 `low`（放宽审核阈值，仅对中等敏感内容有效），如遇上游不支持该参数或需要更严审核，可设为 `auto` 恢复上游默认。

`rewrite_provider_ids` 使用 AstrBot 的有序模型选择器：第一项是主改写模型，后续项按顺序作为回退模型；留空则跟随当前会话。每个模型最多调用 `rewrite_attempts_per_provider` 次。全部改写模型均失败时，本次绘图会终止，不会把未经优化的提示词直接发给图片模型。该选择器在 AstrBot v4.28.0 可用，目前属于 AstrBot 内部配置控件，未来大版本若调整内部接口可能需要随之适配。

图片请求遇到网络异常、限流、5xx 或异常响应时，由 `retries` 控制直接重试；鉴权、权限和参数错误不会进行无意义重试。独立改写模型适合用于提升提示词遵循、中文理解和视觉理解能力，不应用于规避安全规则。

## 配置

配置项及默认值见 `_conf_schema.json`。至少需要填写 `api_key`；默认使用后台出图模式，完成后会主动发送图片。
